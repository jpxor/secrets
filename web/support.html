BEFORE YOU NEED IT

Keep recovery possible.

There is no passphrase reset, maintainer recovery key or Secrets account. A replacement phone needs a valid encrypted backup and the master passphrase. Device biometrics cannot replace either.

Make and test a backup

  1. Keep your passphrase somewhere safe, separate from the encrypted backup.
  2. Export an encrypted vault to an independent location, or configure Google Drive or SFTP and confirm the app reports a successful backup.
  3. Use disposable records to test recovery on a spare device or isolated installation. Keep your existing vault and backup intact while testing.

Restore on another phone

Choose restore before creating a new vault. Connect the same provider or select your encrypted export, then enter the master passphrase. Confirm the recovered records before setting up new biometrics. Import replaces the local vault; it does not merge records. Confirm replacement only after you have protected any existing local data.

Install and update

Android 8 or later is required. When a beta is published, use signed APKs and checksums from GitHub Releases, read their limitations, and allow installation through Android's normal confirmation flow. Update over the existing installation using the same signing identity. Do not uninstall or clear app data to update. Back up first.

Current limitations

Google Drive sign-in and encrypted upload have worked on the maintainer's phone. Fresh-install Drive recovery, sustained background/reboot behavior and a broader device matrix remain release gates. General-user Google production access is not yet verified. Android can delay background work. No independent security audit or stable public release has been completed. Follow the release plan and each release's evidence.

Get help safely

Use GitHub Issues for support. Include app version, Android version, phone model and steps using synthetic records. Never attach a real vault, passphrase, secret, private key or provider token. For suspected security vulnerabilities, use the security policy.
